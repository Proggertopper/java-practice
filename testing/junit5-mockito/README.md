# JUnit 5 and Mockito practice

The existing example project contains calculator tests, parameterized inputs, dynamic tests, tags/platform-specific examples, mocking and interaction verification.

- [Application source](src/main/java/)
- [JUnit / Mockito test source](src/test/java/)
- [Maven configuration](pom.xml)

POM compiler source/target: **Java 17**. Open this POM in IntelliJ or run `mvn test` from this folder with a compatible Maven/JDK setup.

This is a testing-syntax learning project, not a passing regression-suite claim. Platform conditions, tags, lifecycle examples and historical dependency/plugin configuration may affect discovery and results. The complete test suite was not executed during repository organization.
